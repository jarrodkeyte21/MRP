Floor Schedule

Sequences builds across shop tasks against daily hour capacity, using each machine type's own task order.

Builds

Drag the ⠿ handle to reorder — top gets pool hours first each day. Use the small dropdown under Machine type to apply a template. Order date ("auto", dashed) keeps itself updated to when the shop could actually start the job — type a date to pin it as a fixed constraint, or click "↺ Auto" to go back to auto-updating. Lead (days) and hours per task follow the linked template by default — type a value to override just that job (shown in red); click into an overridden number and press R to reset it back to the template value. A notes box appears under a job's hours whenever it has an override, to record why. Track each job's real-world stage using the Status dropdown in Build summary below — moving it past "Scheduled" turns its ORDERED block on the schedule from grey to confirmed.

Task sequence

The shop tasks available and which resource pool each draws from. Add or remove steps freely — sequencing (what must finish before what) is set per job in the Jobs tab. Optionally set a backup pool — if that pool has spare hours left over once its own tasks are covered for the day, this task can draw on them too. Drag the ⠿ handle to reorder — earlier tasks get first claim on a shared pool each day.

Resource pools

Capacity is driven by headcount: employees × shift hours for that weekday, plus overtime if staffed. Set employees and shift length once below; use an override to change headcount for a date range (staff leave, a new hire, public holidays) — shift length and overtime rate stay fixed. Drag the ⠿ handle to reorder pools.
Data syncs live to a shared Supabase project when online, and falls back to this browser's local storage when it can't reach it. Use Export config to back up or share a setup.
